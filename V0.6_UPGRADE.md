# Labb v0.6 upgrade

## Scope
- Dashboard with inventory value, low-stock, expiry, procurement, monthly spend, active-container and recent-usage summaries.
- Inventory detail screen with item profile, container/lot ledger, consumption history, stock health and quick actions.
- Notification Center with deterministic alerts for low stock, expiry, delayed procurement, pending Admin requests and delivered orders awaiting invoice.
- Per-user notification acknowledgement persistence through Supabase RLS.

## Required database migration
Before deploying the v0.6 frontend, run `supabase/migrations/v0.6.sql` in the Supabase SQL Editor.

The migration is additive. It does not alter the existing v0.5 inventory, procurement, container, Storage or audit tables/RPCs.

## Branch workflow
Recommended branch: `feature/v0.6`. Keep `main` as the known-good production branch until live acceptance tests pass.

## Acceptance tests
1. Admin and Member can open Dashboard.
2. Inventory row opens Inventory Detail.
3. Low stock or near-expiry data creates a Notification Center alert.
4. Acknowledging an alert persists after reload for that user only.
5. A second user in the same lab sees their own unacknowledged state.
6. Cross-lab RLS remains intact.
7. Existing consume/order/receive workflows still pass.
