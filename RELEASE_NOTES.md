# Labb v1.0 Final — Release Notes

This is the consolidated production release of Labb for GitHub Pages + Supabase.

## Core laboratory operations
- Shared inventory with physical container/lot ledger
- FEFO material usage and stock reconciliation
- Low-stock/expiry monitoring and per-user acknowledgement
- Procurement approval, ordering, partial/full receiving, invoice and closing workflow
- Vendor records, private documents, audit trail and analytics

## Final modules
- Team and permission administration
- User activation/deactivation at the application/RLS layer
- Equipment registry, bookings, calibration, maintenance and repair history
- Hierarchical room/freezer/shelf/rack/box storage
- Sample registry with slot, quantity, owner, project and expiry
- Equipment/sample operational notifications
- Camera-assisted barcode/QR detection where supported, plus manual and USB/Bluetooth scanner fallback
